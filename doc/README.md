# Txeka Ntiyiso — Plataforma Nacional de Integridade Documental

O **Txeka Ntiyiso** é uma infraestrutura tecnológica de confiança desenhada para garantir a **Autenticidade, Integridade e Não-Repúdio** de documentos digitais em Moçambique, operando em estrita conformidade com a **Lei n.º 3/2017** e o **Decreto n.º 59/2019**.

## Enquadramento Legal
Diferente das Entidades Certificadoras tradicionais, o Txeka Ntiyiso atua como um **Serviço de Registo de Prova e Validação Cronológica**. Utilizamos criptografia de grau militar (SHA-256) para criar selos de integridade que permitem a qualquer cidadão ou instituição validar a veracidade de um documento sem necessidade de aceder ao seu conteúdo sensível.

##  Problemas Resolvidos
- **Erradicação da Fraude Documental:** Validação matemática instantânea.
- **Soberania Digital:** Solução desenvolvida localmente, alinhada com as normas do **INTIC**.
- **Eficiência Administrativa:** Redução de custos com reconhecimento físico de firmas e autenticações manuais.
- **Transparência:** Trilha de auditoria imutável para cada documento emitido.

##  Funcionalidades Core
- **Criptografia SHA-256:** Garantia de imutabilidade absoluta.
- **Sincronização CAT (UTC+2):** Validação temporal conforme a hora oficial de Moçambique.
- **Revogação Auditável:** Gestão de ciclo de vida do documento com registo de motivo.
- **Interoperabilidade B2G/B2B:** API pronta para integração com sistemas governamentais (INAGE, Bancos, Cartórios).
